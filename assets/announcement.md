# 🐚 Maa海螺肉 · v2.0.0-beta.1

### 🌸 欢迎使用新版公开测试版

这一版带来了 **18 项任务**、带 emoji 的任务列表、逐项任务说明，以及默认的 **「日常任务」** 配置。可以按自己的日常习惯勾选运行。

---

## 🎁 可以领取什么？

| 每日领取 | 奖励收尾 |
| :-- | :-- |
| 📅 每日签到 | ✅ 今日任务奖励 |
| 🐱 猫咪体力 | 🗓️ 周常任务奖励 |
| 🤝 好友体力 | 📬 邮件附件并标记已读 |
| 🎁 免费每日惊喜盒子 | 🏖️ 假日清单与计划奖励 |

**🎨 免费十连**：切换到每日素材箱，只有显示「本次免费」才执行绘制十次。

## 🏫 可以完成哪些日常？

- **📋 日程**：进入校园日程，处理对话与完成按钮；已完成时退出。
- **🖼️ 画展**：检查两场展览，领取结束奖励并安排新宣传，可选 **2 / 4 / 8 小时**。
- **💝 出行**：选择第一位人物，赠送蛋糕并按提示互动。
- **🎭 手偶剧场**：观看、暂停、点两次爱心，发送一条英文句号 `.` 留言，再领取观影券。
- **✏️ 速写**：可选择五位男主，识别头像所在地点，收集灵感、连线，选择第一位赠送并返回主页。
- **⬆️ 画灵 / 📜 绘卷升级**：从第一张开始，满级时向后查找可培养的卡。

另有 **🚀 启动游戏** 和 **🔌 连接检查**；启动游戏可选已保存账号昵称片段进行登录记录核对。

## 🚀 第一次运行

1. 打开 MuMu 和 B服游戏，使用 **1600 × 900 横屏**。
2. 在 App 中选择自己的设备，先单独运行「连接检查」。
3. 打开「日常任务」配置，按需勾选项目并检查任务设置。
4. 点击「开始任务」，通过日志查看运行结果。

## 🧩 公测范围，请先看这里

> **速写只支持「架子鼓鼓手」「天体观测」两种题目**，其他题目会停止，需手动完成。

- 默认配置已加入并勾选全部 18 个任务；不需要的任务请先取消勾选。
- 画灵、绘卷升级会消耗材料和金币；出行会消耗礼物；手偶剧场会公开发送 `.` 留言。
- 日常和周常任务只领取已达成的奖励，不代做未完成目标。
- 指定账号登录仅支持当前模拟器已添加且登录过的 B服账号，不会自动注销当前账号。
- 当前主要验证 **Windows x64 + MuMu + B服**；新弹窗和不同界面状态仍可能导致停止。

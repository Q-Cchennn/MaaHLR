# 🐚 Maa海螺肉 v2.0.0-beta.1

## 🌸 2.0 新版公开测试

本次提供 **Windows x64** 压缩包，基于 MFAAvalonia v2.16.2 / MaaFramework v5.12.3，包含GUI、任务资源及OCR模型。完整解压后运行 `Maa海螺肉.cmd` 或 `MFAAvalonia.exe`。

旧版 `v1.1.1` 保留。建议把2.0解压到新目录，避免覆盖旧版本。

## ✨ 这一版有什么？

- 🐚 全新海螺图标、简洁标题及小字号版本号。
- 📋 默认「日常任务」配置，全部18项任务已加入并勾选。
- 📝 每项任务均有说明，支持画展2/4/8小时、五位速写男主和已保存B服账号选择。
- 🎁 签到、猫咪体力、好友体力、免费礼包、假日清单与计划、今日/周常奖励、邮件。
- 🏫 日程、画展、出行赠礼、画灵与绘卷升级。
- 🎨 明确显示「本次免费」才执行的每日素材箱免费十连。
- 🎭 手偶剧场观看、爱心、英文句号留言及观影券领取。
- ✏️ 速写收集、已支持题型连线、赠送和返回主页。

## 🚀 开始使用

1. 下载 `MaaHLR-win-x86_64-v2.0.0-beta.1.zip`，不要下载GitHub自动生成的源码ZIP来代替客户端。
2. 完整解压，双击 `Maa海螺肉.cmd` 或 `MFAAvalonia.exe`。
3. 打开MuMu与绘旅人B服，使用1600×900横屏，选择自己的设备并连接。
4. 先单独运行连接检查，再按需选择日常任务。

需要.NET 10运行环境；无法启动时可检查GUI随附的依赖安装脚本。

## 🧩 公测限制

- 主要验证 Windows x64 + MuMu + B服；其他平台及分辨率尚未验证。
- 速写仅支持「架子鼓鼓手」「天体观测」，其他题目停止。
- 画灵/绘卷升级及赠礼会消耗对应材料；手偶剧场会公开发送一条 `.` 留言。
- 今日任务和周常仅领取奖励，不代做未完成目标。
- 指定账号登录不自动注销当前游戏账号，仅核对已保存的登录记录。
- 遇到新弹窗或未验证状态仍可能卡住，请反馈任务名、失败节点、截图和日志，并遮挡个人信息。

## 📦 文件与检查

- `.zip`：完整Windows客户端。
- `.zip.sha256`：SHA-256下载完整性校验。
- `.validation.json`：发布包完整性及默认配置检查结果。

发布包已检查首次启动、图标、版本号和默认配置，25项自动测试通过；不包含个人账号、设备记录、运行日志和截图。首次启动不会自动执行游戏任务。本轮发布检查不等于全部游戏分支均已实测。

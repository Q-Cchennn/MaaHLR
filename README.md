## 🐚 关于海螺肉

基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 和 [MFAAvalonia](https://github.com/MaaXYZ/MFAAvalonia) 的非官方绘旅人日常助手，提供独立图形界面、18 项任务及「日常任务」默认配置。

当前主要验证环境为 **Windows x64 + MuMu 安卓模拟器 + B服**，模拟器分辨率 **1600 × 900（横屏）**。

> **这是新版公开测试版。** 已接入的功能不代表所有游戏状态都已验证，部分识别和弹窗分支仍会持续调整。首次使用建议逐项测试，再组合运行。

## 🚀 开始使用

### 1. 打开 App

从 [v2.0.0-beta.1 预发布页面](https://github.com/MelinaQ/MaaHLR/releases/tag/v2.0.0-beta.1) 下载 **`MaaHLR-win-x86_64-v2.0.0-beta.1.zip`**（约 127 MiB），完整解压后运行 `Maa海螺肉.cmd` 或 `MFAAvalonia.exe`，窗口显示「Maa海螺肉」。需要验证下载完整性时，可使用同页的 `.sha256` 文件。

已有本地安装的用户也可使用桌面「MaaHLR」快捷方式。首次体验 2.0 建议解压到新目录，不覆盖旧版 `v1.1.1` 的文件。

项目目录中的本地入口为 `install/MaaHLR-Windows/MFAAvalonia.exe`。安装目录不提交到源码仓库，下载源码 ZIP 不等于下载完整客户端。

客户端需要 .NET 10 运行环境；无法启动时，可使用 GUI 随附的依赖安装脚本检查依赖。

### 2. 连接模拟器

1. 打开 MuMu 模拟器及 B服游戏，保持横屏，建议设置为 **1600 × 900**。
2. 在 App 中选择「B服」资源和安卓模拟器控制器，选择自己的设备并连接。
3. 先单独勾选「🔌 连接检查」，确认连接正常。

### 3. 选择日常任务

1. 首次启动提供「日常任务」配置，全部 18 个任务已加入；也可应用同名预设。
2. 按需勾选任务，在任务设置中选择画展时长、速写男主等选项。
3. 游戏已在主页时可直接运行日常；需要启动游戏时勾选「🚀 启动游戏」。
4. 点击「开始任务」，在日志中查看结果。

## ⚙️ 任务设置

| 设置 | 默认值 | 说明 |
| :-- | :-- | :-- |
| 画展宣传时长 | 8 小时 | 可选 2 / 4 / 8 小时，仅影响新申请的展览 |
| 速写男主 | 艾因 | 可选艾因、路辰、罗夏、司岚、叶瑄，按头像定位地点 |
| 使用指定账号登录 | 关闭 | 仅选择当前模拟器内已添加并成功登录过的 B服账号 |

指定账号可填写昵称前三字或其他唯一片段。仅在出现登录记录弹窗时选择和核对，不会自动注销已在游戏中的账号；没有弹窗时，不能保证当前游戏账号就是指定账号。

## 🧩 当前限制

- **速写题库目前仅支持「架子鼓鼓手」「天体观测」**，遇到其他题目会停止，需手动处理。
- 日常、周常奖励任务只领取奖励，不会代做尚未完成的目标。
- 免费十连仅接入每日素材箱的「本次免费」状态，不提供付费抽卡流程。
- 出行已接入部分过渡页面，新活动、陌生弹窗或不同布局可能导致停止。
- Windows + MuMu + B服是当前主要测试组合，其他客户端、平台及分辨率尚未验证。
- 新版 Beta 仍需验证更多账号状态、未完成日程与画展换地点等分支，进度见 [TODO](TODO.md)。

## 💬 问题反馈

遇到卡住、点击偏移或任务失败，请记录：

- App 版本、任务名称和最后一个失败节点；
- 模拟器、分辨率、当时的游戏页面截图；
- App 导出的日志，或 `logs/`、`debug/on_error/` 中对应的内容。

提交前请遮挡昵称、账号记录等个人信息。可以在仓库 Issues 中反馈。

## 🛠️ 开发与本地更新

资源入口为 `assets/interface.json`，流程位于 `assets/resource/pipeline/`。

修改资源后，关闭本地 App，再执行：

```powershell
python tools/update_local_app.py
```

重新打开 App 即可。同步会保留用户已有配置。
